MD V3 Two-Way Sync

MD V3 Two-Way Sync is a personal desktop file preservation tool operated by the owner of the connected Google account. It transfers newly admitted files between authorized Windows computers and the owner's Google Drive storage.

How it works

The tool uses Google Drive API authorization to discover eligible files, read and verify their contents, and create preservation copies in a designated Drive folder. Its operating policy is designed to avoid automatic deletion or overwriting of existing files and to stop on ambiguous conflicts.

The application is intended for private use by its authorized operator, not as a public cloud storage or file-sharing service.

For details about data and OAuth access, see our Privacy Policy.
