Privacy Policy — MD V3 Two-Way Sync

Last updated: 13 October 2026

MD V3 Two-Way Sync is a personal tool used by the operator to synchronize eligible preservation files between authorized Windows computers and the operator's Google Drive. It is not offered as a public service.

Google data accessed

With the account owner's authorization, the application requests Google Drive access to list file and folder metadata; read and verify file content; and create eligible file copies. Google Drive full-access permission may technically allow broader operations, but the synchronization policy is designed not to automatically delete or overwrite files.

Use and storage

Data is used only for the requested file synchronization, duplicate detection, verification, error recovery, and preservation history. Files remain on the operator's authorized computer(s) and Google Drive account. Local synchronization records may contain file paths, file identifiers, checksums, and transfer status. OAuth credentials and tokens are stored in the operator's local Rclone configuration and should be protected by the operator.

Sharing and retention

This application does not operate a separate third-party server for uploading or reselling Google Drive contents. Files and locally recorded synchronization information are retained under the operator's control until the operator removes them. Google's services process data according to Google's own terms.

Access control and revocation

The account owner can revoke the application's access at any time in their Google Account connections settings. The operator can also remove locally stored credentials and synchronization data from their computer. Revoking access stops future authorized API operations but does not automatically delete existing copies.
